# 무료 구성 검증 결과

검증일: **2026-09-23**. Windows / Node.js 24.18 / Chromium.

## 자동 검증

| 명령 | 결과 |
| --- | --- |
| `npm test` | 6개 단위·서버 통합 테스트 통과 |
| `npm run build` | TypeScript 검사 및 Vite 프로덕션 빌드 통과 |
| `npm run test:e2e` | 데스크톱·모바일·태블릿 15개 시나리오 통과 |

## 검증 범위

- 5명 고정 여행자, 의정부팀 3명/울산팀 2명, 날짜별 분기와 귀국 종료 화면.
- 마카오/한국 현지 시간, 자정 경계, 일정 시간 겹침·장소·출처·인원 기준.
- 미인증 여행 데이터 접근 401, 잘못된 접근코드 거부, 인증 후 여행 데이터 접근.
- 이름·팀 변경 요청 405, 교차 출처 로그아웃 요청 403.
- 삭제된 사진 업로드 API와 기존 업로드 이미지 경로 404.
- 운영 모드 테스트 서버를 실제 재시작한 뒤 동일 서명으로 로그인 쿠키와 여행 데이터 유지.
- Render 설정은 `plan: free`, 디스크·데이터베이스 없음. 운영 서버에 파일 저장 의존성 없음.

## 브라우저 시나리오

1440×1000 데스크톱, iPhone 13, iPad 가로 규격의 Chromium 에뮬레이션에서 검사합니다. 모든 시나리오는 JavaScript 실행 오류도 확인합니다.

1. 로그인 → 여행자 선택 → 메인 → 날짜 전환 → 장소 상세 → 큰 주소 → 프로필 → 새로고침 사용자 복원.
2. 울산팀 4일차 종료 안내 → 의정부팀 남은 일정 열람.
3. 준비물 체크 → 시간 시뮬레이션 → 기본 동물 프로필 표시 및 파일 입력 없음.
4. 위치 권한 거부 시 대체 안내·호텔 출발 외부 길찾기 유지, 가로 넘침 없음.
5. 5명 모두 전환, 버튼을 누르기 전 위치 요청 0회, 위치 성공 시 정확도 표시, 위치 사용 중지.

프로필 화면의 사진 선택·크롭·저장 UI를 제거하고 동물 그림, 여행 기간, 항공 일정, 여행자 전환·잠금 기능을 유지했습니다. 화면 캡처는 `test-results/`에 생성됩니다.
