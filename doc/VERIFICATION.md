# 검증 결과

검증일: **2026-09-23**. Windows / Node.js 24.18 / Chromium.

## 자동 검증

| 명령                           | 결과                                                     |
| ------------------------------ | -------------------------------------------------------- |
| `npm test`                     | 6개 단위·서버 통합 테스트 통과                           |
| `npm run build`                | TypeScript 검사 및 Vite 프로덕션 빌드 통과               |
| `npx playwright test`          | 데스크톱·모바일·태블릿 15개 시나리오 통과                |
| `node scripts/screenshots.mjs` | 1440×1050 / 390×844 / 820×1180 화면 캡처, 가로 넘침 없음 |

### 시간·콘텐츠

- 5명 고정 여행자, A팀 3명/B팀 2명.
- 10/12·13 공통, 10/14 오전 공통 후 분기, 10/15 B팀 일정 없음.
- B팀 4일차는 종료 안내를 표시하고 A팀 남은 일정은 명시적 전환으로 확인.
- 마카오 자정 경계, 한국/마카오 1시간 차이, 팀별 귀국 종료 경계.
- 출국 인천 07:50 → 마카오 10:40, 귀국 마카오 16:10 → 인천 22:45를 각각 현지 시간으로 표시.
- 항공 시간차를 실제 비행시간·직항 여부로 표시하지 않음.
- 48개 일정의 시작/끝 유효성, 팀별 시간 겹침 없음, 장소·출처 참조 유효.
- 5/3/2명 예산 기준, 귀국일 출발 3시간 전 공항 도착 제안 확인.
- 시간이 지난 일정을 방문 완료로 표기하지 않음.

### 서버·저장

- 로그인하지 않은 여행 데이터·업로드 이미지 접근 401.
- 잘못된 접근코드 거부, HttpOnly 쿠키 인증 후 데이터 접근.
- 이름/팀 변경 요청 405, 존재하지 않는 여행자 업로드 404.
- 교차 출처 변경 요청 403.
- 가짜 이미지 내용, SVG 확장자, 5MB 초과 업로드 거부.
- 실제 PNG 입력을 512×512 WebP로 재인코딩, EXIF 없음.
- 두 여행자의 동시 업로드를 순차 저장하여 데이터 보존.
- **별도 테스트 서버를 실제 중지·재시작**한 후 사진 메타데이터와 쿠키 복원.
- 손상된 JSON에서 정상 `.bak` 읽기, 기본 사진 복원.

### 브라우저 시나리오

1440×1000 데스크톱, iPhone 13 규격, iPad 가로 규격의 Chromium 에뮬레이션에서 다음을 검증했습니다.

1. 로그인 → 여행자 선택 → 사진 포함 메인 → 날짜 전환 → 상세 → 큰 주소 → 닫기 → 프로필 → 새로고침 사용자 복원.
2. B팀 4일차 종료 안내 → A팀 남은 일정 열람.
3. 준비물 체크 → 3일차 시간 시뮬레이션 → 프로필 사진 선택·크롭·저장·기본 복원.
4. 위치 권한 거부를 주입해 대체 안내·호텔 출발 외부 길찾기 유지.
5. 5명 모두 전환. 사용자가 누르기 전 위치 요청 0회, 위치 성공 시 정확도 표시, 위치 사용 중지.

위치 테스트는 성공·거부 응답을 모의했습니다. 현지 GPS 수신 정확도와 실시간 도로 경로는 마카오 실기기에서 별도 확인해야 합니다. iOS Safari/WebKit 실기기 검증은 수행하지 않았습니다.

## 화면 검토

로그인/여행자 선택, 메인 히어로·탑승권, 모바일 하단 메뉴, 여행 일정, 지도, 사진 크롭 화면을 캡처해 확인했습니다. 820×1180 태블릿 세로에서도 가로 넘침이 없음을 확인했습니다. 모달에는 키보드 포커스 제한과 Escape 닫기를 적용했고, 모션 감소 설정을 지원합니다. 사진 로드 실패 시 카드 영역 유지, 프로필은 동물 그림으로 대체합니다.

검증 과정에서 항공 도착시간 표시, 모바일 메뉴를 흔드는 부모 transform 애니메이션, 4일차 A팀 식사 인원, 프로필 SVG 표시를 보정했습니다. 반복 로그인 검증과 운영 로그인 제한이 충돌하지 않도록 개발 환경은 100회/15분, 운영 환경은 15회/15분으로 분리했습니다.

최종 점검에서 화면 전환 후 Leaflet 줌 전환 콜백이 남는 문제를 보정했습니다. 지도 애니메이션을 끄고 정리 시 이동을 중지합니다. 모든 브라우저 시나리오에 `pageerror` 검사를 추가한 후 **15개 모두 다시 통과**했습니다. Windows 시작 스크립트는 IPv6 `localhost` 확인 지연을 피하도록 `127.0.0.1`을 사용하며 실제 빌드 화면을 브라우저로 열었습니다.
